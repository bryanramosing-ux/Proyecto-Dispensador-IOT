# Documento heredado — NO UTILIZAR EN EL MONTAJE ACTUAL

Este archivo describe la placa perforada y el cableado de la versión anterior con dos HC-SR04, batería 2S, convertidores, panel solar y fusible.

**No usar esta tabla para montar ni energizar la versión USB-C simplificada.** La placa y sus conectores pueden no corresponder al cableado actual (un HC-SR04 de nivel, sin sistema solar ni batería).

Consulte exclusivamente:
- [Conexiones eléctricas USB-C vigentes](../../docs/conexiones_usbc.md)
- [Manual de montaje USB-C](../manual_armado/Manual_de_Armado.md)
- [Lista de materiales vigente](../components/lista_materiales.csv)

No reutilice conectores o placas antiguas hasta comprobar continuidad, pinout, tensión y compatibilidad con el firmware actual.
